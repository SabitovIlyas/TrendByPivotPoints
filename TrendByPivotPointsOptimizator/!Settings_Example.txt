# Пример файла настроек оптимизатора. Строки, начинающиеся не с ключа, игнорируются.
#
# PositionSide: Long или Short (сторона торговли)
# TimeFrames: 01min, 05min, 15min, 30min, 60min или 1d
# Strategy: имя стратегии для универсального оптимизатора:
#     MeanReversion      - возврат к среднему (RSI + SMA-фильтр + ATR-стоп)
#     DonchianUniversal  - прорыв канала Дончиана через универсальный путь
#   Если строка Strategy отсутствует - работает прежний оптимизатор Дончиана.
# Seed: сид генератора случайных чисел; убрать строку - случайный запуск.
# PopulationSize/Generations/CrossoverRate/MutationRate/Patience: параметры
#   генетического алгоритма (умолчания: 100/300/0.85/0.10/50).
# BackwardDays/ForwardDays: окна бэктеста и форвардного теста в днях (1460/1460).
# ForwardPeriodsCount: количество форвардных периодов (10).
# ShiftWindowDays: смещение окна между периодами в днях (30).
# Equity: стартовый капитал (100000). RiskValuePrcnt: риск на сделку, % (2).
# SecuritiesFile: путь к файлу с инструментами; если задан - оптимизатор не
#   спрашивает его диалогом (запуск без интерфейса: передайте путь к этому
#   файлу настроек аргументом командной строки оптимизатора).
# SeedGenesFile: путь к JSON-файлу затравочной хромосомы (необязательно).
# Range:имя:мин:макс:шаг - переопределение диапазона поиска параметра стратегии
#   (по одному параметру на строку; не указанные параметры ищутся в диапазонах
#   по умолчанию). У MeanReversion пороги RSI зависят от стороны: лонг - вход
#   [5;50]/выход [50;95], шорт - вход [50;95]/выход [5;50].
